JS-modules

Small, dependency-free pieces for single-file browser games, taken from Apple Press and Fancy, the Banana. Open any demo, then copy the file you need. Source and docs on GitHub.

  • stage-curtains: Velvet stage curtains that slide shut over a page, then fly open. (docs)
  • save-kit: Safe localStorage saves, backup slot, checksummed copy-paste save codes. (docs)
  • hold-press: Hold-to-repeat for buttons that survives Android Chrome pointercancel. (docs)
  • env-probes: Detects privacy modes that round timers, scramble canvas read-back or block storage. (docs)
  • fx-governor: Steps visual effects down when the device cannot keep up; never back up behind the player. (docs)
  • fly-to-mini: A big element scrolls away and a copy flies to its sticky mini version (and back). (docs)
  • sticker-text: Die-cut sticker lettering in plain CSS text-shadow rings, no images. (docs)
  • idle-core: Tested maths for idle/clicker games: costs, milestones, away income, boost queue, number format. (docs)
  • frame-kit: Frame pacing for canvas games: even-dt smooths the frame time, quality-governor steps effects down and back up, job-pump spreads heavy jobs across frames. (docs)
  • sprite-baker: Tiny software 3D rasterizer that bakes shaded sprites to canvases once at load. (docs)
  • pad-nav: Gamepad API to DOM focus: move through buttons and menus with a controller, no game code. (docs)
  • lzma-decode: Small readable LZMA1 decoder (ES5), tested against Python's lzma. Browsers can only unpack gzip and deflate natively. (docs)
  • cartoon-3d-kit: A written style guide plus demo for the soft, glossy cartoon 3D look done in plain CSS/SVG/canvas. (docs)

Build and test tools: fuzz-play · marionette-lite · single-file-tools · lzma-pack · fuzz-kit

Story tools

Packages for interactive stories, kept with the Story Editor they are cut from (source). Each is MIT-licensed, has no dependencies, and runs in Node 18+ or a browser.

  • story-format: Create, clean, import and export interactive stories as JSON, with a JSON Schema.
  • story-check: Exact checker for branching stories with items, numbers and dice: dead ends and endings no player can reach.
  • story-player: Build one offline HTML game from a story, or play a story from code or a terminal.
  • story-map: Layered, arc and matrix drawings of a story graph (SVG) and seeded simulated players.
  • zip-page: Wrap a finished HTML page into a smaller page that unzips itself, with a pure-JS inflater fallback.
  • qa-kit: Tiered test runner and a Playwright-style API over WebDriver BiDi for stock Firefox; seeded random-story generator.
  • ai-collab-kit: A written process and templates for a person and an AI assistant building software together.
