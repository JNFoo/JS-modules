# Provenance

All code in this repository was written for the game Apple Press by JNFoo with AI assistance (Claude, by Anthropic), then separated from the game and generalized. No third-party source code, fonts or images are included.

Tools in `tools/single-file-tools` and `tools/marionette-lite` call out to separate open-source programs you install yourself (fontTools, brotli, zopfli, svgo, terser, html-minifier-terser, Firefox). Those keep their own licenses and are not part of this repository.

Original game: https://github.com/JNFoo/apple-press
