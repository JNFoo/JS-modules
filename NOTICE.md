# Provenance

All code in this repository was written for the games Apple Press and Fancy, the Banana by JNFoo with AI assistance (Claude, by Anthropic), then separated from the game and generalized. No third-party source code, fonts or images are included.

Tools in `tools/single-file-tools`, `tools/marionette-lite`, `tools/lzma-pack` and `tools/fuzz-kit` call out to separate open-source programs you install yourself (fontTools, brotli, zopfli, svgo, terser, esbuild, html-minifier-terser, Playwright, Puppeteer, Firefox). Those keep their own licenses and are not part of this repository.

Original games: https://github.com/JNFoo/apple-press and https://github.com/JNFoo/fancy-banana (the games themselves are not open source; only the code in this repository is MIT)
